# lean-metric

**Less app, more note.**

一款基于 Flutter 开发的极简笔记式减脂记录应用。

`lean-metric` 是一款轻量级、注重隐私的减脂打卡工具。你可以像在个人笔记本上打卡一样，在一个地方记录每日体重、睡眠、三餐饮食、运动活动与今日状态。

没有冗余死板的食物库，没有烦人的卡路里计算，没有不必要的复杂功能。

简单记录，保持节奏，持续前行。

## ✨ 设计理念

减脂不必很复杂，打卡记录也不应该变得繁重。

市面上许多健身应用内置了极其庞大的食物库、卡路里计算器和复杂的分析图表。`lean-metric` 采用了更纯粹的方式：为你提供一个干净、顺手的打卡空间，记录真正重要的事，而不把日常记录变成另一项沉重的负担。

- **极简设计** — 专注记录，无需繁琐配置。
- **笔记式体验** — 随手记录吃什么、睡多久、做哪些运动。
- **自定义词条库** — 告别繁琐搜索，构建属于你自己的常用餐食与训练词条，一键快捷填入。
- **不精精计较卡路里** — 拒绝死板的食物库与卡路里计算。
- **平滑水肿波动** — 提供 7 天移动平均体重趋势图，帮你剔除体内水分抖动带来的焦虑。
- **100% 本地与隐私** — 所有数据保存在手机本地 SQLite 数据库中，无云端跟踪。

## 📋 核心功能

- **每日体重与空腹记录** — 记录每日体重（kg）与早晨空腹状态。
- **灵活睡眠打卡** — 以“睡眠时长”为主直接填报，支持入睡/起床时间选填与自动计算锁定。
- **步数追踪** — 记录每日步数。
- **饮食与活动随手记** — 早餐、午餐、晚餐、其他饮食、运动活动与今日状态的多行快捷记录。
- **自定义预设词条库 (Phrasebooks)** —
  - *预设饮食*：新增自定义常用餐食与份量（如：`蛋白粉 30g`），在打卡卡片上一键插入并自动换行。
  - *训练记录*：按【力量训练】与【有氧运动】分类管理自定义动作容量（如：`卧推 60kg 5组x10次` / `配速跑 5公里 25分钟`），一键插入每日卡片。
- **交互式数据统计与趋势分析** —
  - 基于 `fl_chart` 的体重趋势折线图，支持在 **原始数据** 与 **平滑水肿**（7天移动平均线）之间自由切换。
  - 时间范围筛选（近 30 天、近 90 天、全部数据）。
  - 周数据汇总卡片（本周平均体重 vs 上周对比 `-0.6kg`、本周日均步数、平均睡眠时长）。
- **数据导出** — 按时间范围（全部、近 7 天、近 30 天、自定义时间段）实时渲染 Markdown 文本，支持一键复制到剪贴板。
- **本地存储与缓存管理** — 基于 SQLite 本地持久化，可在设置中查看存储占用并独立清理缓存。

## 🛠️ 技术栈

- **[Flutter](https://flutter.dev/)** — 跨平台 UI 框架
- **Dart** — 业务逻辑语言
- **SQLite (`sqflite`)** — 本地关系型数据库持久化
- **`fl_chart`** — 数据可视化与趋势图表库

## 🚀 快速开始

### 前置要求

- Flutter SDK (3.13+)
- Dart SDK
- Android Studio 或 VS Code

### 本地运行

```bash
git clone https://github.com/isNineSun/lean-metric.git
cd lean-metric
flutter pub get
flutter run
```
